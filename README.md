# Prof. Dr. Muhammad Farooq Qayyum — Academic Website

Deployable static academic website for Prof. Dr. Muhammad Farooq Qayyum, Professor of Soil Science, Bahauddin Zakariya University, Multan, Pakistan.

## Deploy
This is a dependency-free static site. For GitHub Pages, set **Settings → Pages → Deploy from a branch**, choose `main` and `/(root)`.

## Content sources
Content was consolidated from the current academic CV, BZU faculty profile, and public scholarly/profile records. Web of Science metrics shown on the site are explicitly dated (22 September 2026) because citation metrics change over time.

## Structure
- `index.html` — complete single-page academic site
- `assets/css/style.css` — responsive design
- `assets/js/main.js` — navigation and footer year
- `.nojekyll` — direct static serving on GitHub Pages

## Before public launch
1. Confirm GitHub repository visibility / Pages availability.
2. Add a professional portrait to `assets/images/` if desired.
3. Confirm the exact LinkedIn and Google Scholar profile URLs if they change.
4. Update citation metrics periodically.
